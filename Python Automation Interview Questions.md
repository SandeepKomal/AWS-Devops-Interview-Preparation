# Python Automation Interview Questions

## DevOps-oriented Python topics

- files and directories
- JSON/YAML processing
- HTTP APIs
- subprocess
- exception handling
- logging
- environment variables
- AWS SDK concepts
- pagination
- retries and backoff
- idempotent automation

## Scenario questions

1. Write a script that finds old files and reports their size.
2. Call an API with retries and exponential backoff.
3. Read JSON and extract nested values.
4. List AWS resources and handle pagination.
5. Detect failed deployments and return a useful exit code.
6. Build a script that is safe to run repeatedly.
7. How do you avoid logging credentials?

## Interview principle

Production automation should be observable, idempotent, safely authenticated, failure-aware and easy to test.
