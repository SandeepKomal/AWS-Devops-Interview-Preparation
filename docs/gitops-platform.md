# GitOps and Platform Engineering

## GitOps interview questions

1. What is the desired state?
2. What performs reconciliation?
3. Push vs pull deployment?
4. How do you handle secrets?
5. How do you promote between environments?
6. How do you detect drift?
7. How do you recover from a bad commit?

## Platform engineering questions

1. What problem does an Internal Developer Platform solve?
2. What is a golden path?
3. How is a platform different from a central DevOps team?
4. What should be self-service?
5. How do you measure developer experience?
6. When does an abstraction become harmful?

## Design prompt

Design a platform where a developer can create a service from a template and receive:

- repository
- CI pipeline
- container build
- security scanning
- deployment configuration
- observability defaults
- secrets integration
- production approval path

Explain which pieces are standardized and where teams retain control.
